# Campus Service

## Goal
Campus Service is a simple JavaScript project
created for learning DevOps principles and practices.

## Features
- Addition of two numbers
- Automated unit testing

## How to Run Tests
1. Install Node.js.
2. Open the project folder.
3. Run npm test in the terminal.

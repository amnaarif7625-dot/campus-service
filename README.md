# Campus Service

## Goal
Campus Service is a simple JavaScript project
created for learning DevOps principles and practices.

## Features
- Addition of two numbers
- Automated unit testing

## How to Run Tests
1. Install Node.js.
2. Open the project folder.
3. Run npm test in the terminal.

## Tools Used
- Visual Studio Code
- JavaScript
- Node.js
- Git
- TortoiseGit
- GitHub
- GitHub Actions

## Project Structure

- app.js: Contains the add function.
- app.test.js: Contains automated unit tests.
- package.json: Contains project configuration and test script.
- README.md: Contains project documentation.

## Example

The add function accepts two numbers and returns their sum.

Example:
add(5, 3) returns 8.
